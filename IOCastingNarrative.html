Scene 4 · The #1 input problem

"19" is not the same thing as 19

Text

"19"

Two characters: '1' and '9'.

"19" + 1 → "191"

Number

19

An integer value used in arithmetic.

19 + 1 → 20

Try it

Parse family

int.Parse("25")

→ 25

double.Parse("3.75")

→ 3.75

decimal.Parse("19.99")

→ 19.99

bool.Parse("true")

→ true

char.Parse("A")

→ 'A'

Read this line inside out 
double a = double.Parse(Console.ReadLine());

1. Read text → 2. Parse text into a double → 3. Store the double in a.

Scene 5 · Number type to number type

Casting: moving a value into a different-sized numeric box

byte → short → int → long → float → double

Implicit conversion

Smaller/safe numeric type → larger compatible type.

int students = 32;
double count = students;

No cast syntax required.

Explicit cast

Potentially lossy conversion.

double temp = 72.9;
int whole = (int)temp;

whole becomes 72.

Critical sentence

“Casting a floating-point value to int truncates the fractional part. It does not round.”

Predict each result

The integer-division trap

int points = 7;
int games = 2;

double wrong = points / games;          // 3
double right = (double)points / games;  // 3.5

The right side is evaluated first. int / int performs integer division before the result is assigned to the double.

One more surprise

What does (byte)300 produce in the unchecked/default context demonstrated in this lecture?

Scene 7 · Real users make mistakes

TryParse: safe input without crashing

bool success = int.TryParse(text, out int number);

Parse

Assumes the text is valid. Invalid text throws an exception.

TryParse

Returns true or false. The parsed number comes out through the out variable.

Try it like a student
Instructor wording

“TryParse does not promise that the input is good. It tries the conversion and reports whether it succeeded.”

Predict

bool ok = int.TryParse("abc", out int n);

Common bugs to reinforce
  • Console.ReadLine("Question") — ReadLine takes no prompt argument.
  • int tickets = Console.ReadLine(); — string cannot be implicitly assigned to int.
  • int whole = 4.8; — double cannot be implicitly assigned to int.
  • int n = (int)"5"; — casting does not parse text.
